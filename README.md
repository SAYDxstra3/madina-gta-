# MADINA - لعبة عالم مفتوح بأسلوب GTA (HTML5 / Three.js)

لعبة حركة ومغامرة ثلاثية الأبعاد مفتوحة المصدر تعمل في المتصفح، مستوحاة من عمق وأنظمة ألعابworld المفتوحة مثل GTA V، مع هوية أصلية completely.

## تقنيات البناء
- HTML5 / CSS3 / JavaScript ES6+ (وحدات)
- Three.js (الرسم ثلاثي الأبعاد، PBR، الإضاءة والظلال)
- Cannon-es (الفيزياء، الأجسام الصلبة، التصادم)
- Web Audio API (الصوت المكاني)
- IndexedDB (الحفظ الدائم)

## كيفية التشغيل
1. تأكد من وجود خادم ويب محلي (المتصفح يمنع الوحدات ES modules عند فتح الملف مباشرة عبر `file://`).
2. من مجلد المشروع شغّل:
   - باستخدام Python: `python -m http.server 8080`
   - أو باستخدام Node: `npx http-server -p 8080`
3. افتح المتصفح على `http://localhost:8080`.

## عناصر التحكم (سطح المكتب)
- WASD: الحركة
- الفأرة: تحكم الكاميرا
- Shift: جري
- Space: قفزة
- C: انحناء
- E: ركوب مركبة / salida منها
- F: salida من المركبة (عندما تكون داخلها)
- R: إعادة تحميل السلاح
- النقر الأيسر: إطلاق النار / هجوم
- النقر الأيمن: تصويب
- Tab: تبديل السلاح
- M: opening الخريطة الكاملة
- P أو Esc: إيقاف مؤقت
- G: نظام تحديد المواقع (GPS)
- I: المخزون (إشعار)

## أنظمة اللعبة المنفذة
- مدينة مُنشأة إجرائياً مع مباني، طرق، طرق سريعة، أعمدة إنارة، أشجار وساحة مركزية.
- لاعب ثلاثي الأبعاد مع حركة، جري، قفزة، انحناء، كاميراperson ثالث.
- مركبات يمكن ركوبها وقيادتها مع فيزياء بسيطة.
- حركة مرور تلقائية للمركبات.
- مشاة يتجولون ويتفاعلون مع الخطر.
- نظام الشرطة ومستويات المطلوب (0-6) مع سيارات دورية ومطاردة.
- أسلحة متعددة (م हाथ، مسدس، بندقية دوّاسة، اقتحام، قناصة) مع إطلاق وإعادة تحميل.
- اقتصاد (نقدي وبنكي) مع إيداع وسحب عبر تطبيق الهاتف.
- نظام وقت ونهار/ليل يؤثر على الإضاءة.
- نظام طقس (مطر وجزيئات).
- واجهة مستخدم كاملة (HUD، خريطة مصغرة، هاتف ذكي، قائمة رئيسية، قائمة إيقاف).
- حفظ وتحميل الألعاب عبر IndexedDB.
- مهمة تدريبية أولية مع مكافأة مالية.

## ملاحظات التطوير
هذه النسخة الأساسية القابلة للعب (MVP). لإنجاز المطلوب بالكامل من الماساتká (موديلات ثلاثية الأبعاد حقيقية، أصوات مرخصة، تدمير متقدم، مهام كاملة،eleri) يمكن توسعة الوحدات الحالية وإضافة أصول خارجية بصيغة GLTF/GLB عبر `three/addons/`.
